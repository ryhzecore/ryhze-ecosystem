# Ryhze ecosystem

Development overview for three complementary projects maintained by Ryhze Entertainment.

| Project | Role | Current technology |
| --- | --- | --- |
| Ryhze | Entertainment discovery, installation and launch workflows, with a companion website | Flutter/Dart; Astro/TypeScript website |
| RACE | Game engine and editor for creating and running interactive content | C++20, Qt, SDL and Direct3D 12 |
| Axeon | Programming language and compiler/runtime tooling | Rust and LLVM |

## Intended formation

1. Improve each project's module boundaries, code structure and regression coverage.
2. Qualify each project independently, with Windows first and later platform work following its roadmap.
3. Explore explicit, tested interfaces between language/tooling and engine components.
4. Connect compatible, authorized content to Ryhze's discovery, installation and launch workflows.

This is a development direction. The projects are not presented as a completed or fully integrated ecosystem.

## Publication status

This repository currently contains an overview only. The application, engine and language source remain in private repositories pending a scoped publication review. No software source has been released here or placed under an open-source licence.

The release review covers code ownership and licensing, dependency notices, asset redistribution rights, secrets, personal data and the exact files to publish. Private evidence, credentials, machine-specific records, build outputs and assets without verified redistribution rights are excluded from the planned source release.

No public adoption statistics, production acceptance, or eligibility for an external support program are claimed by creating this repository.
